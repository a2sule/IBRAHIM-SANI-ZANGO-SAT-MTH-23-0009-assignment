# MTH 4208 — FUTB Applied Mathematics Web Suite

## Project
Modular Web Application Development with VS Code

## Files
- `index.html` — HTML5 structure, academic header, MathJax and calculator interface.
- `style.css` — responsive CSS layout, cards, typography and UI styling.
- `script.js` — mathematical computation and validation logic.

## Features
1. Quadratic Equation Solver
   - Validates a ≠ 0.
   - Handles D > 0 (two real roots).
   - Handles D = 0 (repeated real root).
   - Handles D < 0 (complex conjugate roots).
2. Pythagorean Theorem Calculator
   - Validates positive side lengths.
   - Returns c to 4 decimal places.
3. Factorial Calculator
   - Calculates n! for integers 0–170.
4. Bonus Fibonacci Generator
   - Generates 1–30 terms.
5. MathJax / LaTeX mathematical display.
6. Responsive interface for desktop and mobile.

## How to Run
Open the project folder in VS Code and open `index.html` in a browser.
For the MathJax display, an internet connection is normally required because MathJax is loaded from jsDelivr.

## Personalization
Replace `[YOUR NAME]` in `index.html` with your actual name before submission.

## Deployment
The project can be deployed using GitHub Pages or Netlify.
